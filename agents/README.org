#+title: AI skills and configuration
#+author: Pablo Stafforini

My skills, instructions, hooks and supporting tools for Codex and Claude Code.
They cover software development, writing, research, and maintaining my Emacs
and macOS environment.

* Skills

The [[file:skill-inventory.org][skill list]] describes each skill and links directly to its Codex and
Claude Code sources. It brings global and project-local skills together in one
alphabetical list, excluding archived and private skills.

The collection includes code review and debugging, documentation and writing,
research and bibliography workflows, and Emacs and macOS maintenance.

To use a skill, start with its =SKILL.md= and the setup it references. Some skills
are self-contained procedures; others depend on my dotfiles, local commands or
private configuration. Keep supporting files with the skill, preserve any
required repository layout, and supply your own accounts and private inputs.
