This manual describes the features and customization options for the Emacs Lisp file =modus-themes-extras.el=.

* Overview
:PROPERTIES:
:CUSTOM_ID: h:overview
:END:

=modus-themes-extras.el= extends the =modus-themes= package with automatic theme switching based on the operating system's appearance setting. On macOS, both the Emacs Mac port and Emacs Plus provide mechanisms to detect whether the system is in light or dark mode; this package uses those mechanisms to load the appropriate theme without manual intervention.

The light and dark themes are configurable via ~modus-themes-extras-light-theme~ and ~modus-themes-extras-dark-theme~, defaulting to ~modus-operandi~ and ~modus-vivendi~ respectively. Any theme supported by ~modus-themes-load-theme~ can be used (including ~ef-themes~).

The package also provides theme-aware face customizations, particularly for the =highlight-parentheses= package, ensuring that parenthesis highlighting colors stay consistent with the active Modus theme.

The main capabilities are:

- *Configurable theme pair.* Specifying which themes to use for light and dark mode ([[#h:variables][Variables]]).
- *Manual toggle.* Toggling between the configured light and dark themes ([[#h:toggle][Toggle]]).
- *Automatic theme switching.* Detecting the system appearance and loading the configured light or dark theme accordingly, with support for both Emacs Mac and Emacs Plus distributions ([[#h:conditional-theme-loading][Conditional theme loading]]).
- *Theme-aware face customization.* Setting parenthesis highlighting colors from the Modus palette ([[#h:theme-customizations][Theme customizations]]).

* Variables
:PROPERTIES:
:CUSTOM_ID: h:variables
:END:

#+vindex: modus-themes-extras-light-theme
The user option ~modus-themes-extras-light-theme~ specifies the theme to load when the system is in light mode. It defaults to ~modus-operandi~.

#+vindex: modus-themes-extras-dark-theme
The user option ~modus-themes-extras-dark-theme~ specifies the theme to load when the system is in dark mode. It defaults to ~modus-vivendi~.

Both accept any theme symbol. For example, to use ~ef-themes~:

#+begin_src emacs-lisp
(setq modus-themes-extras-light-theme 'ef-maris-light)
(setq modus-themes-extras-dark-theme 'ef-maris-dark)
#+end_src

* Toggle
:PROPERTIES:
:CUSTOM_ID: h:toggle
:END:

#+findex: modus-themes-extras-toggle
The command ~modus-themes-extras-toggle~ toggles between the configured light and dark themes. It reads ~modus-themes-extras-light-theme~ and ~modus-themes-extras-dark-theme~ at call time, so changes to those variables take effect immediately without requiring any additional setup.

This replaces the built-in ~modus-themes-toggle~ (which relies on the static ~modus-themes-to-toggle~ list) with a dynamic alternative that always respects the current values of the user options.

* Conditional theme loading
:PROPERTIES:
:CUSTOM_ID: h:conditional-theme-loading
:END:

#+findex: modus-themes-extras-load-theme-conditionally
The function ~modus-themes-extras-load-theme-conditionally~ is the main entry point for automatic theme switching. It queries the Emacs distribution using ~simple-extras-get-emacs-distro~ (from =simple-extras.el=) and sets up the appropriate mechanism:

- For the *Emacs Mac port* (~'emacs-mac~), it immediately calls ~modus-themes-extras-load-theme-emacs-mac~ to read the current system appearance and load the matching theme.
- For *Emacs Plus* (~'emacs-plus~), it calls ~modus-themes-extras-follow-appearance-emacs-plus~, which loads the theme for the current value of ~ns-system-appearance~ and starts a timer that loads the other theme whenever that value changes.

You would typically call this function once during initialization:

#+begin_src emacs-lisp
(modus-themes-extras-load-theme-conditionally)
#+end_src

** Emacs Mac port
:PROPERTIES:
:CUSTOM_ID: h:emacs-mac
:END:

#+findex: modus-themes-extras-load-theme-emacs-mac
The command ~modus-themes-extras-load-theme-emacs-mac~ reads the current appearance from the =mac-application-state= function. When the appearance is ="NSAppearanceNameAqua"= (light mode), it loads ~modus-themes-extras-light-theme~. When it is ="NSAppearanceNameDarkAqua"= (dark mode), it loads ~modus-themes-extras-dark-theme~. This command can also be called interactively to force a theme refresh.

** Emacs Plus
:PROPERTIES:
:CUSTOM_ID: h:emacs-plus
:END:

#+findex: modus-themes-extras-follow-appearance-emacs-plus
#+vindex: modus-themes-extras-appearance-poll-interval
The function ~modus-themes-extras-follow-appearance-emacs-plus~ loads the theme matching ~ns-system-appearance~ and then checks that variable every ~modus-themes-extras-appearance-poll-interval~ seconds (default 5), loading the matching theme whenever it changes. Calling it again replaces the timer rather than adding a second one. A theme you pick by hand, e.g. with ~modus-themes-extras-toggle~, stays until the system appearance next changes.

It deliberately does not use Emacs Plus's ~ns-system-appearance-change-functions~ hook, and removes this package's function from it. Emacs Plus runs that hook, followed by a forced redisplay, inside an AppKit callback that fires while Emacs is waiting for input. After a theme load there, Emacs stopped running timers and answering the server until the next input event, so a sunrise switch while the display was off blocked Emacs until the display woke (=emacs/freeze-incidents.org=, 2026-11-11). With the hook empty, Emacs Plus only updates ~ns-system-appearance~ and runs nothing else.

#+findex: modus-themes-extras-load-theme-emacs-plus
The function ~modus-themes-extras-load-theme-emacs-plus~ takes an appearance as a symbol (~'light~ or ~'dark~) and loads the corresponding theme from ~modus-themes-extras-light-theme~ or ~modus-themes-extras-dark-theme~.

* Theme customizations
:PROPERTIES:
:CUSTOM_ID: h:theme-customizations
:END:

** Parenthesis highlighting
:PROPERTIES:
:CUSTOM_ID: h:parenthesis-highlighting
:END:

#+findex: modus-themes-extras-highlight-parentheses
The function ~modus-themes-extras-highlight-parentheses~ configures the =highlight-parentheses= package to use colors from the active Modus theme. It retrieves intense background colors (cyan, magenta, green, yellow) and their corresponding foreground colors from the Modus palette via ~modus-themes-get-color-value~ and sets ~highlight-parentheses-background-colors~ and ~highlight-parentheses-colors~ accordingly.

If ~global-highlight-parentheses-mode~ is available, the function also enables it. This function is suitable for use in the ~modus-themes-after-load-theme-hook~ or any theme-switching hook to keep parenthesis colors synchronized with the active theme.

** Extra face customization
:PROPERTIES:
:CUSTOM_ID: h:extra-faces
:END:

#+findex: modus-themes-extras-set-faces
The function ~modus-themes-extras-set-faces~ is provided as a hook point for additional theme-specific face customizations. Its body is currently empty, but its docstring shows how to add conditional face settings based on the active theme:

#+begin_src emacs-lisp
(if (eq modus-themes-extras-light-theme (car custom-enabled-themes))
    (set-face-attribute 'hl-sentence nil :background "#bfefff")
  (set-face-attribute 'hl-sentence nil :background "#004065"))
#+end_src

You can add such expressions to this function and call it from a theme-loading hook to apply per-theme face adjustments.
