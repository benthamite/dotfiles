* Pull request draft

** Title

Track selected non-file buffers without sampling background activity

** Body

The timer currently ignores buffers without a visited file and samples whichever
buffer happens to be current when its callback runs. Agent and chat buffers
therefore disappear from editor activity, and background callbacks can choose
the wrong buffer.

Sample only the selected window of a frame with known focus. Include its buffer
name and working directory, retain the existing file fields, and invalidate the
cached project when the directory changes. Skip project and Git lookup for
remote or nonexistent directories. An optional data hook lets integrations add
local application metadata without adding client dependencies to the watcher.
Deferred mode initialization retains its originating buffer, so its input hook
can restart capture after the idle timer stops it.

The focus API requires Emacs 27.1; the package requirement and README document
that change and the additional recorded metadata. Eight focused ERT tests cover
non-file context, background-buffer rejection, unfocused and disabled buffers,
directory cache invalidation, missing directories, rapid buffer changes and
deferred initialization after buffer switches or teardown.

Live acceptance in the existing Emacs session exercised native deferred
initialization, the idle callback, pre-command restart, selected non-file
capture and an unfocused-frame negative control. The native sender persisted
the non-file context and the local Slack integration's channel and direct
message metadata in a disposable ActivityWatch bucket. The fixture and bucket
were removed. No real Slack channel was opened or contacted by these checks.
