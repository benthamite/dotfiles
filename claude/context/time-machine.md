# Time Machine to the NAS

The full note is private, because it describes Pablo's home network and backup
setup: `~/repos/notes/mac-hardening/time-machine.md`. Read it before
diagnosing a failed or stalled Time Machine backup, a Mac freeze with
unkillable processes, or anything that touches the backup volume or
`/etc/nsmb.conf`.

Two rules from it apply before you have read it:

- The NAS is the backup destination by Pablo's decision. Never propose another
  destination, and never propose that he change how his home is set up: the
  backup must work around his setup, not the reverse.
- The note holds a ledger of causes already ruled out. Check a candidate cause
  against it before investigating or proposing it again.

Keep new findings in the private note, not here: this repository is public.
