#+title: Claude helper commands
#+author: Pablo Stafforini

* Activation and scope

This directory contains Claude-specific service wrappers, test runners, and
configuration installers. There is no =~/.claude/bin= link, and the directory is
not an executable root by itself. Agent instructions and other scripts invoke
these files by their repository paths. A similarly named command elsewhere on
=PATH= is not evidence that the tracked file is active.

* Operational boundaries

=ai-provider-key= keeps provider administrator credentials out of project
repositories and stores project-scoped runtime credentials in the Automations
vault. Before a non-dry-run create or update, its verified monthly spend cap
must match the live provider control and remain within the configured autonomous
ceiling; dry-run mode checks that prerequisite without creating or storing a
credential.

=ahrefs-api-guard= probes the free subscription-usage endpoint before every
paid request and blocks a call that would cross the configured remaining-unit
reserve. Manual Ahrefs calls must use the guarded command; a similarly named
PATH wrapper should not be assumed to be this tracked file without resolving it.

=copy-slack-draft= refuses to overwrite unsent reply input, preserves unrelated
buffers, and verifies the exact staged text. Its errors omit request objects so
credentials carried in HTTP headers cannot reach stderr.

* File index

|------+---------|
| =_gworkspace_auth.py= | Internal OAuth and short-lived token-cache helper shared by the Gmail and Sheets wrappers. |
| =ahrefs-api-guard= | Performs the required free quota preflight before a paid Ahrefs API request. |
| =ai-provider-key= | Provisions and stores project-scoped provider runtime keys while keeping administrator credentials separate. |
| =batch-test.sh= | Loads canonical package source in batch Emacs, rejects stale-load warnings, and emits repository/package/source-revision evidence with a one-time replay-correlation token. |
| =check-elpaca-sync-hook= | Validates the embedded Elpaca sync hook and confirms that the installed hook is identical. |
| =copy-slack-draft= | Copies a Slack draft to the Emacs kill ring and can prefill a thread reply. |
| =cr-worktree-gc.sh= | Removes only clean, fully pushed transient CR review worktrees and preserves unfinished work. |
| =elisp-ert= | Runs profile-aware ERT for a package, test file, and optional test selector. |
| =elisp-check-evidence= | Runs a tracked project-owned non-package Elisp check against the working tree or an explicit index snapshot and emits repository/file/source-revision evidence with a one-time replay-correlation token. |
| =elisp-live-verify= | Waits for a committed package reload or safely removes a deleted package build, requires a non-nil package-named live check, and emits repository/package/commit evidence with a one-time replay-correlation token; a standalone-package label binds the evidence to the package's own checkout regardless of the working directory. |
| =elisp-source-revision= | Computes the Git-and-content identity used to bind Elisp test evidence to the current source. |
| =elpaca-rebuild-wait= | Rebuilds and reloads one Elpaca package with bounded polling, or observes exact source/mirror-bound dotfiles post-commit reload state. |
| =gmail.py= | Provides the multi-account Gmail read, search, draft, send, reply, attachment, and archive operations. |
| =install-skills.sh= | Installs the live interactive and programmatic skill links, then applies skill pruning and private shims. |
| =sheets.py= | Provides the multi-account Google Sheets read, write, append, clear, sheet-management, and metadata operations. |
| =slack.py= | Provides multi-workspace Slack search, history, thread, user, saved-item, and read-state operations. |
| =sync-mcp-servers.sh= | Copies canonical user MCP definitions into account configurations while preserving account-specific environments. |
| =triage-notes= | Runs the Org task triage engine against a personal notes repository, supplying the personal corpus. |
| =update-gworkspace-refresh-token= | Refreshes and stores a selected Google Workspace account token without printing the token value. |

The documentation audit requires every tracked direct child to appear exactly
once in this table. Several wrappers obtain credentials from external stores or
perform remote writes. Inspect the requested account and operation before use,
and never invoke a credential path merely to verify this index.
